# 校园活动管理系统 V1.0 — 项目实现总览

> 本文档把所有步骤的代码整合到一起，说明每个功能需求（FR）和业务规则（BR）在代码中的具体落点，方便小组整体把握项目结构。

---

## 一、整体架构

```
浏览器
  │
  ▼
Controller（页面入口 + 权限检查）
  │
  ▼
Service（业务规则 BR1–BR5）
  │
  ▼
Repository（Spring Data JPA）
  │
  ▼
H2 数据库（db/ 目录，已忽略不入库）
```

---

## 二、功能需求（FR）与代码对应

| 需求 | 用户场景 | Controller | Service | 页面 |
|---|---|---|---|---|
| FR1 注册 | 填写账号密码角色注册 | `UserController.register()` | `UserService.register()` | `register.html` |
| FR2 登录/退出 | 按角色进入不同视图 | `UserController.login()/logout()` | `UserService.login()` | `login.html` |
| FR3 活动发布 | 教师发布活动 | `ActivityController.publish()` | `ActivityService.publish()` | `activity/form.html` |
| FR4 活动浏览 | 学生浏览列表/详情 | `ActivityController.list()/detail()` | `ActivityService.findAllWithEnrollmentCount()` | `activity/list.html`、`activity/detail.html` |
| FR5 报名/取消 | 学生报名或取消 | `EnrollmentController.enroll()/cancel()` | `EnrollmentService.enroll()/cancel()` | `activity/detail.html`（操作入口）、`enrollment/my.html` |
| FR6 名单查看 | 教师查看报名名单 | `ActivityController.enrollments()` | `EnrollmentService.findByActivity()`、`UserService.findNamesByIds()` | `activity/enrollments.html` |
| FR7 活动管理 | 教师结束/取消活动 | `ActivityController.close()/cancel()` | `ActivityService.close()/cancel()` | `activity/manage.html` |

---

## 三、业务规则（BR）与代码落点

| 规则 | 含义 | 落点代码 |
|---|---|---|
| BR1 | 仅教师可发布/管理活动 | `ActivityService.publish()`、`ActivityController` 管理方法中的角色检查 |
| BR2 | 仅报名中（OPEN）活动可报名 | `EnrollmentService.enroll()` 第 1 重校验 |
| BR3 | 报名人数 < 容量上限 | `EnrollmentService.enroll()` 第 2 重校验；数据库联合唯一约束兜底 |
| BR4 | 不可重复报名 | `EnrollmentService.enroll()` 第 3 重校验；`Enrollment` 实体 `(activity_id, user_id)` 联合唯一约束 |
| BR5 | 取消/结束后关闭报名 | `ActivityService.close()/cancel()` 改状态；`EnrollmentService.enroll()` 中 BR2 拒绝 |

---

## 四、核心数据流

### 4.1 注册 → 登录 → 发布 → 浏览

```
/register  ──► UserService.register() ──► app_user 表
/login     ──► UserService.login()    ──► Session 写入 UserSession
/activities/new ──► ActivityService.publish() ──► activity 表（status=OPEN）
/activities     ──► ActivityService.findAllWithEnrollmentCount() ──► 列表页
```

### 4.2 报名 → 名单 → 管理

```
/enrollments（POST）──► EnrollmentService.enroll() ──► enrollment 表
/activities/{id}/enrollments ──► 查询 enrollment + app_user ──► 名单页
/activities/{id}/close|cancel ──► ActivityService.close()/cancel() ──► activity.status 变更
```

---

## 五、关键实体关系

```
app_user (1) ──< (n) activity          教师发布多个活动
app_user (1) ──< (n) enrollment        学生报名多个活动
activity (1) ──< (n) enrollment        活动有多个报名记录
```

## 六、运行入口

- **启动类**：`com.campus.activity.CampusActivityApplication`
- **首页**：`http://localhost:8080/`
- **教师入口**：注册/登录时选“教师”，登录后进入 `/teacher/home`
- **学生入口**：注册/登录时选“学生”，登录后进入 `/student/home`
- **数据重置**：删除项目根目录 `db/` 文件夹后重启
