# 校园活动管理系统 V1.0 — 本地运行指南

> 本指南帮助小组成员在 Windows 本地把项目跑起来，并完成 S1–S6 验证。

---

## 一、环境准备

| 组件 | 推荐版本 | 下载地址 |
|---|---|---|
| JDK | 17+ | https://adoptium.net/zh-CN/temurin/releases/ |
| Maven | 3.9+ | https://maven.apache.org/download.cgi |
| IntelliJ IDEA | 社区版即可 | https://www.jetbrains.com/idea/download/ |

### 检查安装

打开 CMD 或 PowerShell，运行：

```bash
java -version
mvn -version
```

能看到版本号即表示安装成功。

---

## 二、用 IDEA 运行（推荐）

### 2.1 导入项目

1. 打开 IDEA，选择 **Open**（不要选 New Project）
2. 定位到项目根目录 `campus-activity-system/`，选中 `pom.xml`
3. 选择 **Open as Project**
4. 等待 Maven 自动下载依赖（右下角有进度条）

### 2.2 启动项目

1. 打开 `src/main/java/com/campus/activity/CampusActivityApplication.java`
2. 点击左侧绿色小箭头 → **Run 'CampusActivityApplication'**
3. 控制台出现类似以下内容即启动成功：

```
Started CampusActivityApplication in x.xxx seconds
Tomcat started on port(s): 8080 (http)
```

4. 浏览器访问 http://localhost:8080

### 2.3 停止项目

点击 IDEA 顶部红色方块 **Stop** 按钮，或直接关闭 IDEA。

---

## 三、用命令行运行（备选）

在项目根目录双击运行 `start.bat`，或在 CMD 中执行：

```bash
cd campus-activity-system
mvn spring-boot:run
```

首次运行会下载依赖，可能需要 3–10 分钟（视网络而定）。

---

## 四、常见问题

| 问题 | 可能原因 | 解决方案 |
|---|---|---|
| `java 不是内部或外部命令` | 没配 JAVA_HOME | 安装 JDK 并配置环境变量 |
| `mvn 不是内部或外部命令` | 没配 Maven 环境变量 | 解压 Maven 后把 `bin` 目录加入 PATH |
| 端口 8080 被占用 | 其他程序占用了 8080 | 关闭占用程序，或修改 `application.yml` 中的 `server.port` |
| IDEA 提示 `Cannot resolve symbol` | Maven 依赖没下载完 | 右键 `pom.xml` → Maven → Reload Project |
| H2 数据库文件锁定 | 上次未正常关闭 | 关闭 IDEA 后重新启动，或删除 `db/` 目录让系统重新建表 |
| 页面 404 | 没有 Thymeleaf 依赖或模板路径错误 | 检查 `pom.xml` 中是否有 `spring-boot-starter-thymeleaf` |

## 六、项目重启后数据会丢失吗？

默认配置下 H2 数据文件保存在项目目录的 `db/` 文件夹中。只要没有删除该文件夹，重启项目后数据会保留。但 `db/` 目录已在 `.gitignore` 中，不会被提交到 Git。
