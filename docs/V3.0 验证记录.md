# 校园活动管理系统 V3.0 — 验证记录

> 依据：`docs/用户访谈综合需求分析.md` 第五、六节验收场景 S7–S18。
> 本记录由开发小组在本地运行后逐条填写“实际结果”与“是否通过”。

## 验证环境

| 项目 | 内容 |
|---|---|
| 操作系统 | Windows 10/11 |
| JDK 版本 | 17+ |
| 数据库 | H2（嵌入式，自动建表） |
| 运行方式 | IntelliJ IDEA 运行 `CampusActivityApplication` 或 `mvn spring-boot:run` |
| 访问地址 | http://localhost:8080 |
| 测试数据 | 虚构账号（如 teacher01 / student01 / admin），不使用真实个人信息 |

## S7 学生报名需审核活动

| 验证项 | 操作步骤 | 预期结果 | 实际结果 | 是否通过 |
|---|---|---|---|---|
| 报名需审核活动 | 教师发布活动时勾选“需要教师审核”，学生提交报名 | 学生详情页/我的报名显示“审核中” | | |
| 教师通过审核 | 教师在报名名单中点击“通过” | 状态变为“已报名”，学生可见 | | |
| 教师拒绝审核 | 教师在报名名单中点击“拒绝” | 状态变为“未通过审核”，学生可重新报名 | | |

## S13–S18 平台管理（V3.0 新增）

| 编号 | 验证项 | 操作步骤 | 预期结果 | 实际结果 | 是否通过 |
|---|---|---|---|---|---|

| S14 | 查看用户管理 | 进入“用户管理” | 列出所有用户、角色、状态 | | |
| S15 | 停用/启用账号 | 对学生账号点击“停用”，再用该账号登录 | 登录提示“账号已被停用”；启用后可正常登录 | | |

| S17 | 下架/恢复活动 | 对活动点击“下架”，学生登录查看列表 | 学生列表不再看到该活动；恢复后重新出现 | | |
| S18 | 操作日志 | 执行停用/下架后进入“操作日志” | 列表显示对应操作记录、原因、时间 | | |
