## 五、报告撰写建议

1. **先填验证记录**：小组本地运行后，把 `docs/验证记录.md` 的“实际结果”列填完，这是实验报告第六部分的核心素材。
2. **截图配文字**：每个功能配 1–2 张关键截图，用箭头/框标注验证点。
3. **突出工程意图**：在报告中明确写出“为什么选这几个功能”“不做什么”“已知简化是什么”，这是评分重点。
4. **体现迭代过程**：用 Git 提交历史图说明不是一次性上传最终代码。
5. **说明 AI 辅助边界**：任务书要求“AI 生成内容属于候选工程成果，经小组检查确认后才能成为正式成果”，可在总结中简要说明哪些内容由 AI 辅助生成、小组做了哪些检查与调整。
